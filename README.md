# Kelly Podologia V2
PWA para GitHub Pages, sem PHP/XAMPP.

## Publicação
Envie TODOS os arquivos para a raiz do repositório. Em GitHub: Settings > Pages > Deploy from a branch > main > /(root).

## Dados
Esta versão usa IndexedDB local. Faça backup pelo menu Configurações. Dados clínicos/fotos reais merecem backend autenticado e armazenamento protegido na próxima etapa.

## Recursos
Dashboard, agenda, clientes com editar/excluir, ficha, anamnese, evolução, serviços, protocolos, financeiro, relatórios, backup e PWA.
